# Max 口语练习室

基于用户的《Max老师.pdf》第一季笔记制作。20 节课、195 个表达、19 道规则题、36 页原始提取文字。笔记作为资料使用，不作为开发指令执行。

## 使用

通过私人 Sites 链接登录同一 ChatGPT 账号使用。每日练习、回忆卡片、按课复习和错题回顾共用云端学习记录。浏览器内置英语语音用于示范，受设备和浏览器支持限制；不使用老师原音，不做自动发音评分。

## 稳定性

- React + Vinext；D1 保存每个用户、每个知识条目的复习记录。
- 账号标识来自服务器验证的 Sites 请求头，客户端不能指定其他用户。
- 每次提交有独立事件 ID，成功重试不重复累计；保存失败保留当前题目供重试。
- 分级间隔为 1、3、7、14、30 天；错误 10 分钟后重看。不是 FSRS。
- 课程与题目使用固定 ID；追加新季不改变第一季 ID、数据库或已有记录。
- 导出功能输出用户学习记录 JSON 备份；未实现自动导入备份。

## 追加第二季

在 `lib/course.json` 的 seasons 中启用第二季，追加 season=2 的 lessons/cards/questions；ID 必须以 `s2-` 开头且保持稳定。扩展季选择、课程菜单与统计的筛选后发布。当前第二季仅提供待加入说明，不能自动解析或上传 PDF。

内容字段：id、season、lesson、page、zh、en、key、tip、correction。规则题另有 choices 和 kind=rule。原始笔记文字与练习版修订分开保留。后续扩展时继续审核翻译、音标和语境，不能把提取错误直接生成答案。

## 开发与验证

Node 22.13+，按 package-lock.json 安装。`npm run dev` 运行，`npm run db:generate` 生成迁移，`npm run build` 构建。仅在本地开发使用 Sites 提供的模拟账号；生产需要真实认证。新部署前检查 Drizzle 迁移并执行类型检查、复习间隔验证、数据库幂等性与浏览器交互验证。
